# Research portfolio

Education data, research and visualization by Nilkamal Shah. One portfolio hub with K–12, higher education and publications sections. Existing project URLs remain unchanged.

- [Doctoral borrowing](https://nilkamal11.github.io/doctoral-borrowing/)
- [Doctorate careers](https://nilkamal11.github.io/doctorate-careers/)
- [North Palos finance](https://nilkamal11.github.io/district-learning-context-explorer/finance.html)
- [SEDA district explorer](https://nilkamal11.github.io/district-learning-context-explorer/)
- [Illinois Grade 4](https://nilkamal11.github.io/district-learning-context-explorer/illinois.html)
- [K–12 Data Library](https://nilkamal11.github.io/k12-data-library/)
- [Higher Ed Data Library](https://nilkamal11.github.io/higher-ed-data-library/)

Each study includes its sources, definitions and limitations. Related publication: [Indebted Over Time: Racial Differences in Student Borrowing](https://doi.org/10.3102/0013189X19864969).

Also coauthored: [National Trends in Federal Student Loan Borrowing by Income Group and First-Generation Status](https://www.airweb.org/publication/article-148).
